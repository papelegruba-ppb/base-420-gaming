# Base 420 Gaming

Web oficial de **Base 420 Gaming**, espacio gaming y de ocio en Lleida.

## 🎮 Sobre Base 420 Gaming

Base 420 Gaming es un espacio de ocio gaming en **Lleida ciudad**, pensado para jugar de forma individual o con amigos.

El espacio dispone de:

* PlayStation 5
* Consolas para juego local y online
* Partidas multijugador
* Experiencia gaming y de ocio
* Sistema de reservas

## 🌐 Proyecto web

Este repositorio contiene el código fuente de la página web oficial de Base 420 Gaming.

### Tecnologías

* React
* TypeScript
* Vite
* Tailwind CSS
* Lucide React

## 📍 Ubicación

**Lleida, Cataluña, España**

## 📱 Reservas

La web permite a los usuarios consultar la información del espacio y realizar solicitudes de reserva.

## 🚀 Desarrollo y despliegue

El proyecto se desarrolla inicialmente mediante Bolt y se mantiene sincronizado con GitHub.

El despliegue previsto para producción se realizará mediante infraestructura externa a Bolt.
